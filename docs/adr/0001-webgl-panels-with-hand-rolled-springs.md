# WebGL Panels with hand-rolled springs and synthesized sound

Panels must bend at the pointer, which CSS 3D can't do without splitting every Panel into thousands of DOM strips, so the piece renders in WebGL with OGL (a fraction of three.js's size, and all we need is an orthographic camera, instancing and a custom vertex shader). Rustle is a damped spring per Panel with light neighbour coupling, written by hand: rigid-body engines like Rapier don't model bending sheets and would add a large WASM payload for ~30 lines of math. Haptics were dropped because iOS only allows them on discrete taps, not during a drag, which can't deliver the "flipping pages" feel; synthesized Web Audio Chimes carry the tactile feedback instead: each Panel Rustled past plays a note pitched by its length, with no audio files.
